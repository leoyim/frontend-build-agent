# 前端打包构建：从底层原理到工程实践

> 一本由真实互动教学沉淀而成的技术电子书。

## 这本书是什么

2026 年 10 月 8 日至 10 日，一位有 HTML/CSS/JS 与 npm 基础的开发者，以「资深前端工程化专家」为对话对象，用三天的分节互动教学走完了四个模块、二十二节内容，主题是**前端打包构建工具**：

1. **核心原理** —— 依赖图、入口与输出、Loader/Plugin、Tree Shaking、代码分割、HMR、Source Map、开发与生产模式差异
2. **Webpack 与 Vite** —— 打包式构建与原生 ESM 开发服务器的架构分野
3. **新一代构建工具** —— esbuild、SWC、Rspack、Farm、Turbopack、Rolldown，以及 AI 辅助构建
4. **学习路径** —— 分阶段顺序、动手项目、文档与源码的阅读切入点

本书把这三天的讲解、追问、批改与纠错，重组成一本**可以独立阅读、系统复习、实践验证**的知识读物。

它不是聊天记录。对话被按知识依赖重新组织，零散解释被合并成完整讲解，重复内容被去重。**唯一被刻意保留的"过程痕迹"，是那些有学习价值的反例、认知误区和纠错过程** —— 它们进了 `notes/correction-log.md` 与各章的「常见误区」。

## 怎么读

| 你的情况 | 建议路径 |
|---|---|
| 想建立完整心智模型 | 按顺序读 01 → 07 |
| 只想知道 Webpack 和 Vite 怎么选 | 03 章 → 07 章 §7.5 决策矩阵 |
| 手上有个老项目想提速 | 04 章 §4.3（Rspack）→ 07 章 §7.6（迁移评估） |
| 想复习关键结论 | `notes/knowledge-cards.md`（知识卡片）+ `appendix/glossary.md` |
| 想看踩过哪些坑 | 各章「常见误区」+ `notes/correction-log.md` |
| 想动手 | `practice/exercises.md`（五个动手项目）+ `practice/experiments.md` |

**阅读约定**：正文中的结论分三类，均已标注 —— **【已学】**（课程中讲解并互动确认过）、**【补充背景】**（课程未覆盖，本书为补齐上下文而加入的通识内容）、**【待验证】**（课程中提出但未经实测或官方文档复核的推断）。详见 `METADATA.md` 的范围声明。

## 给谁看

- 前端开发者中**已经会用**构建工具、但说不清「为什么」的人
- 需要为团队做**构建工具选型与迁移决策**的人
- 想理解 Rust/Go 构建工具这一轮换代，在发生什么、该不该跟进的人
- 需要一份**可复用的技术学习方法论**（而不只是知识点）的人

前提：会写 HTML/CSS/JS，装过 npm 包，跑过 `npm run dev` / `npm run build`。
