# assets/

本目录用于存放**图片、附件等二进制资源**。

## 当前状态：空

本书**不需要任何二进制资源**，原因如下：

| 内容类型 | 本书的处理方式 | 为什么不用图片 |
|---|---|---|
| 概念图、流程图、时序图 | **Mermaid** 内联代码块 | 纯文本可 diff、可版本控制、随主题自动适配、不依赖外部资源 |
| 对比内容 | Markdown 表格 | 可搜索、可复制、可无障碍阅读 |
| 配置示例 | `practice/examples/` 下的代码文件 | 可直接运行、可被编辑器高亮 |
| 代码片段 | 围栏代码块 | 同上 |

## 为什么刻意不用图片

1. **纯文本可 diff** —— 改一张图在 Git 里是"二进制文件变化"，改一段 Mermaid 是"可见的文本差异"。
2. **无失效风险** —— 图片路径断掉、图床挂掉、截图过期，都不会发生。
3. **可搜索** —— 图片里的文字搜不到，Mermaid 源码里的文字可以。

## 如果将来要加图片

放在本目录，并在正文中用**相对路径**引用：

```markdown
![说明文字](../assets/xxx.png)
```

添加后请运行 `tools/link_check.py` 校验路径有效性 —— 该脚本会检查图片引用是否指向真实存在的文件。
