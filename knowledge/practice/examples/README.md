# 配置示例

本目录的示例配置用于演示第 2、3 章讲解的机制，**不是可直接复制的生产模板**。

| 文件 | 演示的机制 | 对应章节 |
|---|---|---|
| `webpack.config.js` | 缓存三件套、Loader 顺序、splitChunks、dev/prod 分叉、Source Map 策略 | §2.2、§2.3、§2.5、§2.7、§2.8 |
| `vite.config.ts` | 默认值覆盖、别名、环境变量、manualChunks、library mode 硬坑 | §3.3、§3.4、§3.6、§7.5 |

## 使用建议

**读法**：每个配置块都写了注释说明「为什么这么配」和「不这么配会怎样」——**注释比配置本身更重要**。

**动手验证**：把某个配置项删掉，观察产物变化。这比读配置有效得多（对应 §7.3 台阶 2 的判据）。

**不要照抄**：这些示例里包含了一些**为演示而刻意保留的非最优写法**（例如把 `lodash` 整包导入然后再用按路径导入做对比），并已用注释标出。
